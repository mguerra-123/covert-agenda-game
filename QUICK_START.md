# Quick Start Guide 🚀

## Get the Game Running in 3 Steps!

### Step 1: Install Python Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Start the Game
```bash
python start_game.py
```
OR
```bash
python app.py
```

### Step 3: Open Your Browser
Go to: **http://localhost:5000**

---

## What You'll See:

1. **Landing Page**: Beautiful welcome screen with game features
2. **Registration**: Create your account (username, email, password)
3. **Dashboard**: Your game hub where you can create or join games
4. **Game Room**: Where the magic happens - get challenges and compete!

---

## Quick Test:

1. Register a new account
2. Create a game (you'll get a 6-digit code)
3. Open another browser tab/window
4. Register another account
5. Join the game using the code
6. Start playing!

---

## Troubleshooting:

- **"Module not found"**: Run `pip install -r requirements.txt`
- **Port 5000 busy**: The app might already be running
- **Styling issues**: Clear browser cache or refresh the page

---
